# Registro de decisiones de arquitectura (ADR)

Cada decisión de diseño importante se documenta aquí como un archivo numerado.
Sirve para dos cosas: que el grupo no vuelva a discutir lo mismo cada semana, y
que en la sustentación oral cualquiera pueda responder por qué se eligió una cosa
y no otra. La rúbrica del Ex1 pide de forma explícita "justificación de decisiones
de diseño" con peso 14.

Formato: contexto, opciones evaluadas, decisión, consecuencias.
